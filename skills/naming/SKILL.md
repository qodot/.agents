# 코드 이름 짓기

1. 이름을 정하기 전에 같은 파일과 디렉터리의 선언, 호출부, 테스트를 읽는다. 저장소 전체에서 같은 역할의 구현과 관련 용어를 검색하고, 도메인 용어집이 있으면 함께 확인한다. 발견한 이름의 뜻과 용례를 비교해 같은 개념에는 같은 단어를 쓰고, 같은 역할에는 같은 문법 구조와 표기법을 따른다.
2. 변수, 모듈, 클래스는 대상의 역할을 설명하는 명사나 명사구로 짓는다. 함수는 실제 동작을 나타내는 동사를 중심으로 짓고, 대상을 구분해야 할 때만 목적어를 붙인다. 기준은 필요한 의미를 보존하는 가장 짧은 이름이다.
3. 형용사와 부사는 실제로 구별해야 하는 동작, 상태, 범위를 표현할 때만 쓴다. 후보에서 단어를 하나씩 빼 보고 의미와 구분이 유지되면 뺀다.
4. 이름을 영어 구절로 읽어 단어의 뜻, 품사, 어순, 단수와 복수가 실제 역할과 맞는지 확인한다. 함수 이름의 동사는 호출자가 결과를 어떻게 예상하는지 기준으로 고르고, 선택한 이름을 선언과 대표 호출부에서 다시 읽어 주변 코드와 일관되는지 확인한다.
